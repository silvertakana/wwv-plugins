# wwv-plugin-exif-geolocate

OSINT sidebar tool for WorldWideView: upload a photo and it reads the EXIF GPS tags to drop a pin on the globe where the photo was taken.

Works on any JPEG/HEIC with embedded GPS metadata; the resulting pin keeps the photo as its entity image.

Originally created with WorldWideView community contributor (dontshome); adapted and maintained by WorldWideView.
