# wwv-plugin-phone-lookup

OSINT sidebar tool for WorldWideView: type or paste a phone number and get its country/region and number type (mobile, fixed line, toll-free, etc.) straight from the number's format.

Results drop a pin on the globe at the detected country's centroid, and past lookups are kept in the sidebar.

Originally created with WorldWideView community contributor (dontshome); adapted and maintained by WorldWideView.
